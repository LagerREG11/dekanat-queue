# Деканаттың электрондық кезегі

Қорқыт Ата атындағы Қызылорда университеті деканатына арналған электрондық кезек жүйесі (5-нұсқа, Web: Flask + SQLite). Студент талонды онлайн алады және күту уақытын көреді, деканат қызметкері студенттерді панель арқылы шақырады, декан мен оның орынбасары аккаунттарды, жұмыс кестесін және қызметтерді басқарады.

## Орнату

```bash
python -m venv .venv
```

```bash
.venv\Scripts\activate
```

```bash
pip install -r requirements.txt
```

Linux / macOS: `source .venv/bin/activate`.

## Іске қосу

```bash
flask --app app.web run
```

немесе

```bash
python run.py
```

Браузерде: http://127.0.0.1:5000

Телефоннан кіру үшін (компьютер мен телефон бір Wi-Fi желісінде): `run_phone.bat` немесе `python run.py --lan`. Терезеде телефонға арналған мекенжай мен QR-код шығады; Windows брандмауэрі сұраса, «Рұқсат беру» басыңыз.

## Тесттер

```bash
pytest
```

Қамту есебімен:

```bash
pytest --cov=app --cov-report=term
```

Соңғы нәтиже: 359 тест өтті, жалпы қамту 93% (service.py — 99%, chatbot.py — 100%, db.py — 96%).

## Баптаулар

| Айнымалы | Мәні |
|---|---|
| `SECRET_KEY` | Сессия кілті (берілмесе, `instance/secret_key` файлында жасалады) |
| `QUEUE_DEMO` | `0` (әдепкі) — талон тек жұмыс күндері 08:45–18:00 беріледі; `1` — демонстрация үшін уақыт тексерілмейді |
| `PUBLIC_URL` | QR-кодтағы мекенжай (әдепкіде автоматты анықталады) |
| `COOKIE_SECURE` | HTTPS арқылы жұмыс істегенде `1` |
| `SHOW_DEMO_ACCOUNTS` | `0` — кіру бетінде демо-аккаунттар кестесін жасыру (хостингте міндетті) |

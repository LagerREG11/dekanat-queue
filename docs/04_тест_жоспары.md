## Тестілеу кезінде табылған қателер
- Бір SQLite қосылымы ағындар арасында ортақ болғандықтан бет 500 қатесін берді — әр сұрауға жеке қосылым жасалды (TC-16).
- Windows консолі қазақ әріптерін шығара алмай сервер құлады — шығыс UTF-8-ге ауыстырылды.
- Миграцияда жаңа баған қосылғаннан кейін кесте сипаттамасы қайта оқылмады — түзетілді (TC-15).
- Декан «Деканат» қойындысында тұрып кірсе, қате шығатын — қойынды енді кіруді шектемейді (test_login_works_from_any_tab).
- Телефонда басты беттің суреті (aspect-ratio + min-height) бетті көлденеңінен кеңейтіп жіберді — биіктігі тікелей берілді.
- Рефакторингтен кейін (30 жолдан ұзын функцияларды бөлу) барлық 366 тест қайта іске қосылып, өтті — мінез-құлық өзгермегені расталды.

# Хостингке орналастыру (PythonAnywhere)

Сайт мекенжайы: `https://ЛОГИН.pythonanywhere.com` (ЛОГИН — PythonAnywhere аккаунтының аты).

## 1. Аккаунт
1. https://www.pythonanywhere.com → **Pricing & signup** → **Create a Beginner account** (тегін).
2. Логин, e-mail, құпиясөзді өзіңіз енгізіп, e-mail-ды растаңыз.

## 2. Кодты жүктеу (Bash консолі)
**Consoles → Bash** ашып, кезекпен:

```bash
git clone https://github.com/GITHUB_ЛОГИН/dekanat-queue.git
cd dekanat-queue
python3.12 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

## 3. Веб-қолданба
1. **Web → Add a new web app → Next → Manual configuration → Python 3.12 → Next**.
2. **Virtualenv** өрісіне: `/home/ЛОГИН/dekanat-queue/.venv`
3. **Source code**: `/home/ЛОГИН/dekanat-queue`
4. **WSGI configuration file** сілтемесін ашып, бар мәтінді толық өшіріп, мынаны қойыңыз да, **Save** басыңыз:

```python
import os
import sys

PROJECT = "/home/ЛОГИН/dekanat-queue"
if PROJECT not in sys.path:
    sys.path.insert(0, PROJECT)

os.environ["SHOW_DEMO_ACCOUNTS"] = "0"   # кіру бетінде демо-құпиясөздерді жасыру
os.environ["COOKIE_SECURE"] = "1"        # HTTPS арқылы ғана cookie
os.environ["QUEUE_DEMO"] = "1"           # 0 — талон тек жұмыс кестесі бойынша
os.environ["PUBLIC_URL"] = "https://ЛОГИН.pythonanywhere.com/"

from wsgi import app as application  # noqa: E402
```

5. **Security → Force HTTPS** — қосыңыз.
6. Беттің жоғарғы жағындағы жасыл **Reload** батырмасын басыңыз.

`SECRET_KEY` бөлек орнатудың қажеті жоқ: алғаш іске қосқанда `instance/secret_key` файлында кездейсоқ кілт жасалады (ол GitHub-қа түспейді).

## 4. Іске қосқаннан кейін міндетті түрде
Демо-аккаунттардың құпиясөздері README-де ашық жазылған. Сайтқа кіріп, **Профиль → Құпиясөзді өзгерту** арқылы ауыстырыңыз:
- `admin` (әкімші), `zamdekan` (декан орынбасары), `dekanat1`, `dekanat2` (әдіскерлер).
Немесе әкімші панелінде қажет емес демо-аккаунттарды өшіріңіз / бұғаттаңыз.

## 5. Жаңарту
Кодты өзгерткен соң компьютерде `git push`, сосын PythonAnywhere Bash консолінде:

```bash
cd ~/dekanat-queue && git pull && .venv/bin/pip install -r requirements.txt
```

да, **Web → Reload** басыңыз. Дерекқор (`instance/dekanat.db`) жаңартуда сақталады.

- Сырттан тек рұқсат етілген сайттарға қосылуға болады (сайтқа әсері жоқ).
